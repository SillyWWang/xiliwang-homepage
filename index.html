Work Experience

Meituan LongCat Team, Mar 2025 - Sep 2025
Research intern and core member for agentic tool use, working on tool-use data synthesis, supervised fine-tuning, and reinforcement learning for multi-turn LLM agents.

  • Built automated multi-turn tool-use data synthesis pipelines based on Multi-LLMs and MCP. The pipelines cover both simulated tool outputs with task-specific virtual databases and real MCP tool execution through user-agent-tool interactions.
  • Used the synthesized multi-turn tool-use data for SFT of LongCat-Flash-Chat, improving its agentic tool-use capability. LongCat-Flash-Chat achieved TAU2 Retail 71, TAU2 Airline 58, and TAU2 Telecom 68 on TAU2-Bench.
  • Worked on a multi-turn user-interacting reinforcement learning framework for agentic tool use. The work introduces LLM-simulated users into RL rollout so that agents learn to clarify dynamic user requirements, maintain task state, and coordinate tool calls over long interactions.
